# Simple Interest Calculator

This is a simple interest calculator project.

### Formula:
Simple Interest (SI) = (P * R * T) / 100
- **P** = Principal amount
- **R** = Annual rate of interest
- **T** = Time period in years

### Example:
- Principal = 1000
- Rate = 5%
- Time = 2 years
- Simple Interest = (1000 * 5 * 2) / 100 = 100
